# Loadout randomizer for Helldivers II game

## 1. Installing
- Run [randomdive_installer.exe](randomdive_installer.exe).

## 2. Usage
It has a simple use:

- Run installed app;
- Choose which warbonds you want to use;
- Choose randomize weapons or not;
- Press only button;
- Try to play your next dive with what you rolled.
